## 已观察到的字形与解释差异

- 注疏写“泰小往大來吉亨”，本义写“小徃大來”；“往／徃”是本次实际观察到的字形差别。标点须另行记录，不冒充古籍原有断句。
- 两份材料初九均写“彚”，样章写“汇”；注疏九三用“无”，本义六四用“冨”。后续须明确繁简和异体字归一规则，不能将未经说明的转换称为逐字相同。
- 注疏大象写“財成”，音义记录“荀作裁”；保留样章“财成”，不擅改成“裁成”。
- 九二“用冯河”：已裁决（负责人，2026-11-25），白话及要点保持四种品质说，备注并列不同读法。王弼注“能包含荒穢受納馮河者也”（摘录第 35 行），孔疏“无舟渡水……是頑愚之人此九二能包含容受”（第 41 行）支持将莽撞涉河者解释为九二包容的对象；《本义》第 6–7 行侧重“包容荒穢而果斷剛决”。现代学者读“包”为“匏”及汉代注家读“荒”的说法由负责人提供，来源为二手汇编，待核原书（高亨《周易古经今注》、虞翻、郑玄），核实后再补出处。
- 九三“孚”：注疏侧重诚信自明，本义说“所期之信”；六四六五及“自邑告命”的白话仍待逐项核定。
- 六五“帝乙归妹”：已裁决（负责人，2026-11-25），白话采用“帝乙嫁女（一说嫁妹），由此得福，大吉。”，要点保持并注明为义理解读。注疏摘录第 78–87 行以出嫁释“归”，并以降身应二说明义理；《本义》第 13–14 行侧重柔中虚己、下应九二。帝乙身份与归妹含义的说法由负责人提供，来源为二手汇编，需对照《周易注疏》泰六五疏及《本义》核对，不落实为具体史事。

以上观察中，九二、六五仅已裁决读法；原文与引文措辞仍待多底本核对，其余事项保持待核。`npm run validate` 验证结构数据、来源爻位标签、泰卦模板与引用路径，不验证这些释义差异；所有卦保持 `status: draft`。
