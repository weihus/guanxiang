# 地基部分六章详细大纲（已确认并调整）

## 教学主线与材料安排

六章按“看清线 → 认识八卦 → 拆合六画 → 找关系 → 读时位 → 分清经传”的顺序展开，与 PRD 的六个地基主题对应。完成后，读者应能独立拆解任一六画卦，按上下卦查到卦名，再进入原文阅读；脱离速查表辨认全部卦名的熟练度，随六十四卦正文逐步积累。

六章顺序已确认。八卦角色卡单列于 `docs/M2-TRIGRAM-CARDS.md`，第二章写作时再编入；当前只授权第一章试点，完成校验与两端构建后停止。其余章节不随大纲确认自动展开。

贯穿人物采用角色卡的统一设定：虚构人物林舟和街坊整理社区共享小院，为周末开放日做准备。林舟仅用于八卦角色卡与地基部分；后续六十四卦页的【设想】各自独立。人物故事负责提供记忆画面；取象、术语和原文判断分别列出处。泰卦是贯穿拆卦、关系、时位及经传阅读的主样章，其他卦先用图、名称和结构作对照。

每章控制在 3000–5000 字；统计时列明正文、表格与练习答案的字数口径。每章均以章末练习和参考答案收尾，引用改为脚注，同节同源只标一次；编校备注仅在draft显示。网页与 PDF 使用同一份章稿、题干和答案，网页答案默认折叠，PDF答案另页。

## 第一章　一条线怎样成为卦：阴阳、爻与读图方向

**本章主问题：看到六条线时，怎样准确地读出它的结构？**

### 拟设小节

1. **先认两种线。** 解释爻、阳爻、阴爻，用实线与断线辨形；把阴阳放在成对的结构关系中讲，区分线形与价值褒贬。
2. **三画与六画各是什么。** 用图展示一个三画卦和一个六画卦，说明本书“八卦”指八个三画基础卦，六十四卦由上下两个三画卦组合。
3. **从下往上读。** 将一幅图逐层高亮，从最下面读到最上面，先掌握六个位置；用“初、二、三、四、五、上”标出位置。
4. **下三爻与上三爻。** 画分组括号，认出内外卦（下卦与上卦的另一组称呼），为第三章拆合做准备。
5. **九与六怎样出现在爻名里。** 只说明九是阳爻的命名、六是阴爻的命名，以初九、六四认出爻的性质与位置；不展开来历。如确需涉及来历，放备注并明确存在多种说法。
6. **经的两层。** 在九六命名之后、读图检查之前用约半页说明卦辞面向整卦、爻辞分属每一爻，给第五章预备阅读概念，第六章再深入经传结构。

### 本章必须回答

- 一条断线为什么仍算一爻，而不是两爻？
- 图的第一爻为什么从下数？读图时怎样避免上下颠倒？
- 三画卦与六画卦为何可能同名，却不是同一幅图？
- “初九”的“初”和“九”分别说明什么？
- 说某爻是阴爻、某一位置是第四位，是不是同一回事？
- 卦辞与爻辞分别面向整卦还是某一爻？怎样从书页上找到它们？

### 图表与例子

- 两种爻形对照图；三画／六画并排图；六位自下而上编号图。
- 用泰卦现有 SVG 展示分组和爻名，暂不展开卦义。
- 数据依据：`data/trigrams.yaml`、`data/hexagrams/11-tai.yaml`。阴阳、刚柔及六画结构的原文线索用《说卦》相关段落，逐字核对后再编入正文。

### 练习与完成标准

- 题目拟设：数出阴阳爻并分上下；给泰卦六位排序并补爻名；辨认卦辞／爻辞归属。
- 完成标准：能从下至上读完六条线，并正确分出上下各三条，不要求此时背全八卦名称。

## 第二章　八个基本角色：从自然之象记住八卦

**本章主问题：怎样把八幅三画图、八个卦名和八组基本特征记成一套？**

### 拟设小节

1. **先分开三种信息。** 卦名回答“它叫什么”，自然之象回答“取什么形象”，德性回答“用哪个词概括其特点”；给出并列小表。
2. **八张角色卡。** 按乾、坤、震、巽、坎、离、艮、兑依次展开，每张包含卦图、主象、德性原词、词义助记和同一小院里的【设想】。
3. **父母与六子。** 完整列出乾父、坤母、震长男、巽长女、坎中男、离中女、艮少男、兑少女，说明这是文本中的取象关系。图中比较三男的阳爻位置和三女的阴爻位置；“一索、再索、三索”的进一步解释另标注疏层。
4. **两个容易读错的字。** 保留离的“丽”和兑的“说”，分别说明孔疏的附着解释、陆德明音义的悦读；将传文、释字、作者助记排成三栏。
5. **从关键词回到图。** 用配对练习，将图形、卦名、自然之象和德性来回对应；巽保留木、风，离保留火、日、电，避免把一卦固定成唯一自然物。

### 本章必须回答

- 健、顺、动、入、陷、丽、止、说各对应哪一卦？
- “丽”与“说”在这里分别怎样理解、怎样读？
- 巽为什么在卡上同时出现木与风？离为什么有火、日、电？
- 父母六子的对应怎样帮助记忆八卦关系？
- 林舟故事中的动作，怎样回扣原词，又怎样与传文事实区分？

### 图表与例子

- 八卦五字段总表；八张角色卡；父母六子关系图；离／兑释字对照栏。
- 已核文字依据：`references/shuogua-citations.yaml`。后续成章时按引用登记回查具体底本页码，将孔疏与音义标成解释层。

### 练习与完成标准

- 题目拟设：看三画图说卦名；给八个德性词找对应图；从同一小院场景指出所帮助记忆的原词。
- 完成标准：能辨认八个三画卦，能给出本章选取的自然之象、德性与家庭称谓对应；能分清词义助记和原文。

## 第三章　怎样一眼认卦：上下卦的拆合与查名

**本章主问题：一幅六画卦图，怎样拆成两个熟悉的三画卦，再找到卦名？**

### 拟设小节

1. **先切成下三画与上三画。** 固定“先读下、再读上”的操作顺序，分别写出三画卦名。
2. **两个角色放到一起。** 用下乾上坤的泰卦示范，由两个基本角色进入全卦的取象；经文和注释为义理解读提供依据。
3. **上下交换后发生什么。** 将泰、否两图并排，沿用已有泰卦样章的沟通比喻，指出位置变化，记录两卦名称；否卦先作结构对照。
4. **八乘八怎样成为六十四。** 用上下卦交叉表查名，说明通行卦序是另外一套排列；结构相似与卦序相邻分别观察。
5. **固定认卦四步。** 读六线、分上下、认三画、查名称；最后核对卦符、卦序和上下卦标签。原文阅读接在认卦之后。

### 本章必须回答

- 上乾下坤与下乾上坤为什么不能混成同一卦？
- 同一个三画卦放在上或下，图上哪些部分会改变？
- 八卦交叉表怎样使用？横轴、纵轴各约定什么？
- 按上下卦查名与按第几卦查名，各适合什么情况？
- 认清结构后，为什么还要回到本卦文字理解处境？

### 图表与例子

- 泰卦拆合分镜；泰／否并排；上下卦交叉速查表。
- 数据依据：M1 全量 YAML 与 `data/generated/hexagrams.csv`。交叉表的轴向必须在表头明确标注。

### 练习与完成标准

- 题目拟设：看六画图查出卦名；按指定上下卦画图；纠正一个把上下卦标反的例子。
- 完成标准：拿到任一六画卦图，能独立拆出上下卦，并用速查表准确查名。

## 第四章　卦与卦怎样连起来：错、综与互

**本章主问题：怎样对同一幅图作三种操作，并看懂它与其他卦的关系？**

### 拟设小节

1. **错：逐爻阴阳互换。** 保持爻位不动，实线换断线、断线换实线，用逐层着色图展示。
2. **综：六爻上下倒序。** 明确整幅图的倒转，区分“上下三画互换”与“六爻次序整体反转”。
3. **自综与同时为错、综。** 举数据中的自综结构；用泰／否说明一对卦可以兼有两种关系。
4. **互：取中间四爻，重组上下三画。** 下互卦用原卦二三四爻，上互卦用三四五爻。明确保留各组自下而上的次序，展示重叠爻。
5. **关系事实与象数解释。** 算出哪一卦属于结构事实；据这种关系解释原文属于象数解读，须另列出处并标“象数解读，非定论”。

### 本章必须回答

- 错、综分别改变什么，又保留什么？
- 为什么有些卦倒过来仍是自己？
- 同一对卦为什么可以既是错卦，又是综卦？
- 互卦为什么是二三四／三四五，而不是随便取中间两组？
- 连续取两次互卦，是否一定回到原卦？

### 图表与例子

- 泰卦错综分步图；泰互卦的取爻着色图；关系类型图例。
- 数据依据：`data/generated/relations.json`，保留自综、自互和重合关系。正文成章前补核错综互术语及互体解释的注本出处；《说卦》“八卦相错”一语与本章操作定义的联系须单列说明，不能直接当成同义证明。

### 练习与完成标准

- 题目拟设：画出指定卦的错、综；标明泰卦互卦取用了哪些原爻；分辨结构计算与象数解释两类陈述。
- 完成标准：能按图独立完成三种操作，并说明互卦关系通常不要求反向互指。

## 第五章　卦序与六爻时位：先分清顺序，再看处境怎样展开

**本章主问题：卦在全书的位置、爻在一卦的位置，分别能帮助我们读懂什么？**

### 拟设小节

1. **两个层级的顺序。** 卦序是六十四卦的排列，爻位是一卦内部的六个位置；用两条尺度不同的图示分开。
2. **上经、下经与成对阅读。** 展示上经一至三十、下经三十一至六十四；通行卦序按奇偶分成三十二对，其中二十八对相综，四对自综卦以错相配。把配对方式与《序卦》的文字说明分别列证据。
3. **先标清位，再看词。** 用泰卦六爻图标出初二三四五上，不将图的位置直接写成起势、得吉、转凶等判断。需要解释具体处境时，爻辞和小象分别列出并核对出处；小象先用一句话说明是解释该爻的传文，第六章再详讲。
4. **主线只讲位、中、当位。** 位置用初二三四五上；中只说明二、五；当位按爻位奇偶与阴阳配合陈述结构事实。初、上定位的不同注法另列出处说明。对泰卦的释义或吉凶判断必须对照爻辞和小象逐项给出处，不能由位置或当位直接推出。
5. **承、乘、应只放旁栏。** 各用一两句话，核对出处，不设练习。地基部分不引入六亲、世应、纳甲、六神等占筮体系术语。

### 本章必须回答

- 第十一卦与第三爻分别说的是哪一层位置？
- 三十与三十一为何是上下经边界，却不是本章奇偶配对的一对？
- 为什么不要求所有连续两个编号都互为错或综？
- “居中”“当位”各在描述什么？为什么还要看爻辞？
- 仅凭“九三当位”能否判断具体处境？还要对照哪些爻辞和小象文字？

### 图表与例子

- 六十四卦分经带状表；三十二卦对简表；泰卦位、中、当位三栏结构表；二、五居中示意图。
- 数据依据：M1 的卦序、上下经与关系数据。文本依据：泰卦已保存底本；关于初、上定位的不同意见，现存《周易注疏》说卦部分已有注释线索，正式写作前还需核对《周易略例》等相应篇章。

### 练习与完成标准

- 题目拟设：区分卦序与爻位；按卦图指出二、五居中；按奇偶约定判断泰卦各爻是否当位，将这些结构事实与爻辞／小象的解释分栏。承、乘、应不设练习。
- 完成标准：能把卦序、结构位置、爻辞和教学时间线分层说明，不将位置公式直接当作吉凶结论。

## 第六章　经与传怎样读：带着一张地图进入泰卦

**本章主问题：翻开一卦时，怎样知道自己正在读哪一层文字，并完成一次有依据的阅读？**

### 拟设小节

1. **先认卦辞与爻辞。** 在泰卦页面上标出全卦层与逐爻层，认识经文的基本组织。
2. **再认彖、大象与小象。** 并排说明它们各自解释或阐发的对象，给原文、白话加清楚标签。
3. **十翼的篇目地图。** 用简图标出彖上下、象上下、系辞上下、文言、说卦、序卦、杂卦之间的计数关系和阅读用途；篇目与成书、作者问题分开处理，年代和作者判断核实后再写。
4. **经传混排本怎样找层次。** 用泰卦片段练习定位；指出本项目样章目前主要展示卦辞、彖、大象和爻辞，小象等将按正文需要另行核对取用。
5. **做一次完整阅读。** 看卦图、认上下、查卦名、读卦辞、对照彖象、沿六爻读处境变化、查看错综互、完成练习；每一步回指前五章。
6. **读懂书中的标记。** 集中解释原文引用、白话、【设想】、备注别说、象数解读与审校状态，告诉读者如何沿引用记录查证。

### 本章必须回答

- 卦辞与爻辞分别说明什么范围的事情？
- 彖、大象、小象各在解释什么？
- 为什么“十翼”不能简单理解成十个完全不同的篇名？
- 一句话来自传文、后世注释或作者白话，怎样从版面上辨认？
- 看到有争议的解释时，怎样追到出处？
- 读完一张新卦图，怎样按固定步骤完成入门阅读？

### 图表与例子

- 经传层次示意图；十翼篇目地图；泰卦阅读路线图；引用及状态标记图例。
- 已有材料：泰卦样章与 `docs/REVIEW.md`。十翼篇目、混排方式及小象的具体引文须在成章前据底本核对，本大纲不预填未核原文。

### 练习与完成标准

- 题目拟设：给泰卦片段标出经传类型；区分传文、注疏、白话与设想；按六章所学完成一次拆卦及查证。
- 完成标准：能独立拆图、查名、辨经传层次，并说明一条白话解释的文字依据。
